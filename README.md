# Конструктор упаковки и этикеток — портфолио на ComfyUI

Доказательство двухслойного пайплайна: **нейросеть делает только плоскую графику**, а вырубка, живой текст,
CMYK и вылеты считаются отдельно и детерминированно. В репозитории — рабочие workflow в API-формате ComfyUI,
индекс кейсов и валидатор, который проверяет графы без запуска ComfyUI.

Все графы собраны **только из встроенных нод** ComfyUI 0.43.0: открываются на чистой установке без custom nodes.

## Как устроена генерация

1. **Бриф → числа.** Размер берётся из брифа, а не «на глаз»: `px = (мм + 2 × вылет) / 25.4 × 300`.
   Этикетка 70×120 мм с вылетом 3 мм → 76×126 мм → **898×1488 px**. Генерация идёт в SDXL-бакете
   1024×1664 (кратно 8), hi-res ×1.5, а финальный `ImageScale` с `crop: center` приводит кадр к точным
   898×1488 px: соотношения близки (1.625 и 1.657), поэтому срез ~2% по ширине уходит в вылет,
   а не в безопасную зону, и графика не растягивается.
2. **Графика — единственное, что делает сеть.** В промпте и negative-листе прямо запрещены текст, тени,
   перспектива и мокап: всё это нельзя тащить в печать, и всё это сеть рисует «сама», если не запретить.
3. **Структура — отдельно от стиля.** Референс идёт через Canny + ControlNet, стиль задаётся промптом:
   так меняется вид, не ломая композицию заказчика.
4. **Правки — по маскам, а не заново.** Каждый инпейнт видит результат предыдущего (`GrowMask` на 8–12 px,
   чтобы не было шва), область вне маски остаётся пиксельно прежней.
5. **Контур — маской, не картинкой.** `ImageColorToMask(#FFFFFF) → InvertMask → GrowMask(+2 px)` даёт альфу,
   а `MaskToImage` — отдельный файл вырубки для раскладки.

## Как запустить

```powershell
# Проверить графы и индекс — офлайн, без ComfyUI и torch
python tools/validate_workflows.py

# Убедиться, что валидатор не «декоративный»: подбросить ему 10 дефектов
python tools/selftest_validator.py
```

**В ComfyUI.** Файлы лежат в API-формате `{node_id: {class_type, inputs}}` — это формат, который принимает
`POST /prompt` и который отдают скрипты автоматизации. Открыть граф глазами: `Workflow → Open` →
`workflows/01_brief_to_label_artwork.json`; если ваш фронтенд не импортирует API-формат, запускайте
программно (ниже) — результат тот же.

**Программно.** Возьмите `script_examples/basic_api_example.py` из дистрибутива ComfyUI, замените
`prompt_text` на содержимое нужного файла — формат совпадает один в один, per-node `_meta` сервер
игнорирует:

```python
prompt = json.load(open("workflows/01_brief_to_label_artwork.json", encoding="utf-8"))
queue_prompt(prompt)   # POST /prompt на запущенный `python main.py`
```

```powershell
# Обновить снимок каталога нод после апгрейда ComfyUI
python tools/snapshot_node_catalog.py --comfyui C:\ComfyUI
```

## Что проверяет валидатор

* JSON — объект вида `{node_id: {class_type, inputs}}`, без лишних ключей верхнего уровня (ComfyUI их отвергает);
* `class_type` есть в каталоге встроенных нод, все обязательные входы заполнены, неизвестных входов нет;
* типы значений совпадают с объявленными в ноде (`INT` ≠ `1.5`, `STRING` ≠ число, где нужна связь — пришла связь);
* ссылки `["id", slot]` ведут на существующую ноду и в пределах её числа выходов;
* в графе нет циклов, каждая нода влияет на результат (иначе — предупреждение об осиротевших нодах);
* в `portfolio.json` ссылки `coverage[].where` живые, а все файлы из `files` существуют на диске.

## Покрытие ТЗ

Кратко: генерация по брифу, референсы и пакетные правки — закрыты (кейсы 01–05); геометрия и правка
«до пикселя» — частично (растр + раскладка); CMYK/ICC, живой текст и векторная вырубка — сознательно
вне ComfyUI и закрываются на шаге сборки печатного файла. Детали с обоснованием — в `portfolio.json`
(`coverage`, `boundaries`).

## Что заменить перед боевым запуском

В графах стоят правдоподобные имена моделей-заглушек. Замените их на свои файлы из `models/`:

| Нода | Сейчас | Куда класть файл |
|---|---|---|
| `CheckpointLoaderSimple.ckpt_name` | `sd_xl_base_1.0.safetensors` | `models/checkpoints` |
| `CheckpointLoaderSimple.ckpt_name` (инпейнт, кейс 03) | `sd_xl_base_1.0_inpainting_0.1.safetensors` | `models/checkpoints` |
| `ControlNetLoader.control_net_name` (кейс 02) | `controlnet-canny-sdxl.safetensors` | `models/controlnet` |
| `LoadImage.image` | `refs/moodboard_pine_label.png`, `masks/LB-2026-014/edit_01_ornament.png` | `input/refs/`, `input/masks/` |

Имена должны совпадать с файлами буквально — ComfyUI не подставляет похожие.

Отдельно про передачу между кейсами: `SaveImage` пишет в `output/labels/LB-2026-014/`, а `LoadImage`
читает только из `input/`. Поэтому арт, который кейсы 03 и 05 правят и обрезают по контуру, сначала
копируется из `output/labels/...` в `input/labels/LB-2026-014/print_art_v1.png` — под этим именем его
и ждут графы.
