# Принты на текстиле и мерче — портфолио на ComfyUI

Репозиторий: https://github.com/viramax43-art/comfyui-textile-print-portfolio

Доказательство двухслойного пайплайна: **нейросеть делает только плоскую графику принта**, а физический размер,
контур под DTF и ограничение палитры красок считаются отдельно и детерминированно. В репозитории — 7 рабочих
workflow в API-формате ComfyUI, индекс кейсов и валидатор, который проверяет графы без запуска ComfyUI.

Два кейса выходят за пределы печати и показывают вторую половину работы с ComfyUI: **видео из статичного
принта** (кейс 06) и **пакетная подготовка партии исходников** без генерации вообще (кейс 07).

Все графы собраны **только из встроенных нод** ComfyUI 0.43.0: открываются на чистой установке без custom nodes.

## Как устроена генерация

1. **Бриф → числа.** Размер берётся из брифа, а не «на глаз»: `px = см / 2.54 × dpi`.
   Принт 30×40 см → `30 / 2.54 × 300 = 3543.3 → 3543 px` и `40 / 2.54 × 300 = 4724.4 → 4724 px`.
   Генерация идёт в SDXL-бакете 1024×1368 (пропорция 0.748 против 0.75 у 30×40 — искажения нет),
   hi-res ×2 → 2048×2736, а финальный `ImageScale` с `crop: center` приводит кадр к точным 3543×4724 px.
2. **Графика — единственное, что делает сеть.** В промпте и negative-листе прямо запрещены текст, тени,
   перспектива, мокап и фактура ткани: всё это нельзя тащить в печать, и всё это сеть рисует «сама».
3. **Структура — отдельно от стиля.** Эскиз идёт через Canny + ControlNet, стиль и палитра задаются промптом:
   так меняется вид, не ломая композицию заказчика.
4. **Правки — по маскам, а не заново.** Каждый инпейнт видит результат предыдущего (`GrowMask` на 8–12 px,
   чтобы не было шва), область вне маски остаётся пиксельно прежней.
5. **Контур — маской, не картинкой.** `ImageColorToMask(#FFFFFF) → InvertMask → GrowMask(+2 px) → JoinImageWithAlpha`
   даёт PNG-24 с прозрачностью, `MaskToImage` — отдельный контур под трассировку,
   `ImageQuantize(colors 8, dither none)` — версия под шелкографию без градиентов.

## Два проекта вне печати

**Кейс 06 — кадр → ролик.** Готовый принт масштабируется в видео-бакет 832×480 и уходит стартовым кадром
в `WanImageToVideo`. Модель: Wan 2.1 i2v (fp8), энкодер umt5, `ModelSamplingSD3 shift 8.0`, сэмплер
`uni_pc / simple`, 20 шагов. Длина 65 кадров — это 4n+1, требование архитектуры; при 16 fps получается
цикл ~4 секунды. На выходе `SaveAnimatedWEBP` — файл сразу годится в карточку товара и в соцсети,
печатный файл из него не собирается.

**Кейс 07 — партия без генерации.** Детерминированный конвейер: `UpscaleModelLoader` →
`ImageUpscaleWithModel` (×4 без перерисовки) → `ImageScale` в ровно 3543×4724 px → `ImageBatch` →
`SaveImage`, и та же партия через `ImageQuantize` в 8 красок. Ни чекпойнта, ни промпта, ни сида:
результат повторяем на любом железе, а исходник 800 px такой граф не «спасёт» — это апскейл, а не генерация.

## Как запустить

```powershell
# Проверить графы и индекс — офлайн, без ComfyUI и torch
python tools/validate_workflows.py

# Убедиться, что валидатор не «декоративный»: подбросить ему 10 дефектов
python tools/selftest_validator.py
```

**В ComfyUI.** Файлы лежат в API-формате `{node_id: {class_type, inputs}}` — это формат, который принимает
`POST /prompt` и который отдают скрипты автоматизации. Открыть граф глазами: `Workflow → Open` →
`workflows/01_brief_to_print_artwork.json`; если ваш фронтенд не импортирует API-формат, запускайте
программно (ниже) — результат тот же.

**Программно.** Возьмите `script_examples/basic_api_example.py` из дистрибутива ComfyUI, замените
`prompt_text` на содержимое нужного файла — формат совпадает один в один, per-node `_meta` сервер
игнорирует:

```python
prompt = json.load(open("workflows/01_brief_to_print_artwork.json", encoding="utf-8"))
queue_prompt(prompt)   # POST /prompt на запущенный `python main.py`
```

```powershell
# Обновить снимок каталога нод после апгрейда ComfyUI
python tools/snapshot_node_catalog.py --comfyui C:\ComfyUI
```

## Что проверяет валидатор

* JSON — объект вида `{node_id: {class_type, inputs}}`, без лишних ключей верхнего уровня (ComfyUI их отвергает);
* `class_type` есть в каталоге встроенных нод, все обязательные входы заполнены, неизвестных входов нет;
* типы значений совпадают с объявленными в ноде (`INT` ≠ `1.5`, `STRING` ≠ число, где нужна связь — пришла связь);
* ссылки `["id", slot]` ведут на существующую ноду и в пределах её числа выходов;
* в графе нет циклов, каждая нода влияет на результат (иначе — предупреждение об осиротевших нодах);
* в `portfolio.json` ссылки `coverage[].where` живые, а все файлы из `files` существуют на диске.

## Покрытие требований

Кратко: генерация по брифу, референсы, пакетные правки, колористика, контур и ограничение палитры закрыты
кейсами 01–05; пакетная подготовка партии — кейсом 07; промо-видео — кейсом 06. Геометрия и точный размер
закрыты растром (растр + `ImageScale` + апскейл-модель), а CMYK/Pantone, живой текст, векторная трассировка
и бесшовный раппорт сознательно вне ComfyUI и закрываются на шаге препресса. Детали с обоснованием —
в `portfolio.json` (`coverage`, `boundaries`).

## Что заменить перед боевым запуском

В графах стоят правдоподобные имена моделей-заглушек. Замените их на свои файлы из `models/`:

| Нода | Сейчас | Куда класть файл |
|---|---|---|
| `CheckpointLoaderSimple.ckpt_name` (кейсы 01, 02, 04) | `sd_xl_base_1.0.safetensors` | `models/checkpoints` |
| `CheckpointLoaderSimple.ckpt_name` (кейс 03, инпейнт) | `sd_xl_base_1.0_inpainting_0.1.safetensors` | `models/checkpoints` |
| `ControlNetLoader.control_net_name` (кейс 02) | `controlnet-canny-sdxl.safetensors` | `models/controlnet` |
| `UNETLoader.unet_name` (кейс 06) | `wan2.1_i2v_480p_14B_fp8_e4m3fn.safetensors` | `models/diffusion_models` |
| `CLIPLoader.clip_name` (кейс 06) | `umt5_xxl_fp8_e4m3fn_scaled.safetensors` | `models/text_encoders` |
| `VAELoader.vae_name` (кейс 06) | `wan2.1_vae.safetensors` | `models/vae` |
| `UpscaleModelLoader.model_name` (кейс 07) | `4x-UltraSharp.pth` | `models/upscale_models` |
| `LoadImage.image` | `refs/sketch_wildflower_layout.png`, `masks/TS-2026-041/edit_01_sprig.png`, `photos/TS-2026-052/source_A.png` | `input/refs/`, `input/masks/`, `input/photos/` |

Имена должны совпадать с файлами буквально — ComfyUI не подставляет похожие. Файлы в таблице — примеры
канонических сборок, а не единственный вариант: подойдёт любая модель той же архитектуры
(SDXL-чекпойнт, canny-ControlNet под SDXL, Wan 2.1 i2v, ESRGAN-апскейлер).

Отдельно про передачу между кейсами: `SaveImage` пишет в `output/prints/TS-2026-041/`, а `LoadImage`
читает только из `input/`. Поэтому принт, который кейсы 03 и 05 правят, а кейс 06 анимирует, сначала
копируется из `output/prints/TS-2026-041/` в `input/prints/TS-2026-041/print_art_v1.png` — под этим
именем его и ждут графы.
