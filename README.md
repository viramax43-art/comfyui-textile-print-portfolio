# Принты на текстиле и мерче — портфолио на ComfyUI

Репозиторий: https://github.com/viramax43-art/comfyui-textile-print-portfolio

Доказательство двухслойного пайплайна: **нейросеть делает только плоскую графику принта**, а физический размер,
контур под DTF и ограничение палитры красок считаются отдельно и детерминированно. В репозитории — 7 рабочих
workflow в API-формате ComfyUI, индекс кейсов и валидатор, который проверяет графы без запуска ComfyUI.

Два кейса выходят за пределы печати и показывают вторую половину работы с ComfyUI: **видео из статичного
принта** (кейс 06) и **пакетная подготовка партии исходников** без генерации вообще (кейс 07).

Все графы собраны **только из встроенных нод** ComfyUI 0.43.0: открываются на чистой установке без custom nodes.


## Два проекта вне печати

**Кейс 06 — кадр → ролик.** Готовый принт масштабируется в видео-бакет 832×480 и уходит стартовым кадром
в `WanImageToVideo`. Модель: Wan 2.1 i2v (fp8), энкодер umt5, `ModelSamplingSD3 shift 8.0`, сэмплер
`uni_pc / simple`, 20 шагов. Длина 65 кадров — это 4n+1, требование архитектуры; при 16 fps получается
цикл ~4 секунды. На выходе `SaveAnimatedWEBP` — файл сразу годится в карточку товара и в соцсети,
печатный файл из него не собирается.

**Кейс 07 — партия без генерации.** Детерминированный конвейер: `UpscaleModelLoader` →
`ImageUpscaleWithModel` (×4 без перерисовки) → `ImageScale` в ровно 3543×4724 px → `ImageBatch` →
`SaveImage`, и та же партия через `ImageQuantize` в 8 красок. Ни чекпойнта, ни промпта, ни сида:
результат повторяем на любом железе, а исходник 800 px такой граф не «спасёт» — это апскейл, а не генерация.

## Как запустить

```powershell
# Проверить графы и индекс — офлайн, без ComfyUI и torch
python tools/validate_workflows.py

# Убедиться, что валидатор не «декоративный»: подбросить ему 10 дефектов
python tools/selftest_validator.py
```

**В ComfyUI.** Файлы лежат в API-формате `{node_id: {class_type, inputs}}` — это формат, который принимает
`POST /prompt` и который отдают скрипты автоматизации. Открыть граф глазами: `Workflow → Open` →
`workflows/01_brief_to_print_artwork.json`; если ваш фронтенд не импортирует API-формат, запускайте
программно (ниже) — результат тот же.

**Программно.** Возьмите `script_examples/basic_api_example.py` из дистрибутива ComfyUI, замените
`prompt_text` на содержимое нужного файла — формат совпадает один в один, per-node `_meta` сервер
игнорирует:

```python
prompt = json.load(open("workflows/01_brief_to_print_artwork.json", encoding="utf-8"))
queue_prompt(prompt)   # POST /prompt на запущенный `python main.py`
```

```powershell
# Обновить снимок каталога нод после апгрейда ComfyUI
python tools/snapshot_node_catalog.py --comfyui C:\ComfyUI
```
